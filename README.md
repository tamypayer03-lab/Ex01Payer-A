Descriptive Memory

Proportions and Measurements
I set up a fixed workspace of 800x800 pixels (createCanvas(800, 800)).

Grid and Lines: The composition is structured by vertical and horizontal black lines of different thickness (strokeWeight(9) and strokeWeight(11)):
- Main vertical line at x = 350.
- Main horizontal lines at y = 300 and y = 450.
- Secondary vertical lines at x = 90 and x = 650.
- Secondary horizontal line at y = 750 between x = 350 and x = 650.

Boxes: The colored areas were reproduced using the rect() function by entering the precise coordinates of the rectangles calculated on the grid.

Choice of Colors
The primary colors typical of Mondrian's works have been reproduced in RGB format:
Background: Very light gray/Off-white rgb(239, 239, 239)
Red: rgb(224, 31, 38) (top left)
Yellow: rgb(247, 230, 70) (bottom left)
Blue: rgb(15, 71, 140) (bottom center)
Lines: Pure black rgb(0, 0, 0)
